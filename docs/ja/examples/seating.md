# 座席表

クリックまたはドラッグで座席を選び（Shift で追加選択）、状態を設定します。描画はカスタムの `seat` シェイプが担当しています。

## 画面に出ていない部分

キャンバスをクリックして <kbd>Tab</kbd> を押してみてください。最初に到達するのは、表示中の座席1つにつき1つのボタンです。それぞれに座席番号と状態のラベルが付いており、実行するとその座席が選択されます。右のパネルは冒頭の数件を映して中身を見えるようにしたものです。**本物のリストは視覚的に隠されています。あなたに向けたものではないからです。**

これは座席表に後付けした機能ではありません。**コントロール層がどこにあるかから自動的に出てくる**ものです。選択 UI をキャンバスに描くライブラリには、アクセシビリティツリーに辿れるものが何もなく、後から与えることもできません。ピクセルは要素ではないからです。Konva と Fabric はハンドルをキャンバスに描きます。それがトレードオフです。

リストは表示範囲に仮想化されているので、1万席の会場でも DOM に載るノード数は有界のままで、残りは件数として報告されます。ズームアウトして、パネル下の要約を見てみてください。[アクセシビリティ →](/ja/guide/accessibility)

## 座席は、ライブラリが知らないシェイプ

`seat` は `rect` や `text` と**同じ** `ShapeUtil` インターフェースで登録されています。組み込みだけの特権的な経路は存在しません。拡張点が本当に十分かを確かめる方法はそれしかないからです。

```ts
interface SeatShape extends ShapeBase<'seat', { label: string; status: SeatStatus }> {}

declare module '@headless-canvas/core' {
  interface ShapeRegistry {
    seat: SeatShape
  }
}
```

declaration merging が `props` の型付けを支えています。これがないと `createShape({ type: 'seat', … })` はすべて `any` に落ちます。

真似する価値のある点が2つあります。

- **`canRotate: false`。** 座席は回転しないので、回転ハンドルは提供されません。宣言するのはシェイプ側で、UI 側は座席のことを何も知りません。このアプリは後述のとおりハンドルを全部消していますが、**それでも宣言はシェイプに置くべきです。** 座席がどこで使われても真だからです。
- **`getPath` ではなく `toSvg`。** 座席は「塗られた輪郭」ではなく**箱とラベル**なので、自分でマークアップを書きます。SVG に書き出すと座席番号も一緒に出てきます。書き出し側は座席が何かを知らないまま、シェイプに尋ねているからです。[カスタムシェイプ →](/ja/guide/custom-shapes)

## シェイプのラベルを翻訳する

`getAccessibleLabel` はシェイプが文章を生成する唯一の場所で、組み込みシェイプはメッセージ表を経由せず英語を返します。これは手抜きではなく**意図的な設計**です。ラベルはシェイプの**中身**に依存するので、固定の翻訳キー集合では、まだ誰も書いていない型を記述できません。

サポートされている翻訳方法は**シェイプ実装ごと差し替えること**で、このアプリがやっているのがまさにそれです（そもそも2言語のラベルが必要なので、都合もよい）。

```ts
const seatShapeUtil = (lang: Lang): ShapeUtil<SeatShape> => {
  const _ = t(lang)
  return {
    type: 'seat',
    // …
    getAccessibleLabel: (shape) =>
      `${_(['Seat', '座席'])} ${shape.props.label}, ${_(STATUS_TEXT[shape.props.status])}`,
  }
}

new Editor({ container, shapeUtils: [...defaultShapeUtils, seatShapeUtil(lang)] })
```

組み込みシェイプの差し替えも同じ手順です。`...defaultShapeUtils` の**後ろ**に自分の実装を置けば、そちらが勝ちます。

## 選択だけできて、変形はできない

座席は一度並べたら、あとは選ぶだけです。移動やリサイズは機能ではなく**座席表を壊す手段**にしかならないので、どちらも提供していません。そして取り除くのにフォークは要りません。

**ツール。** 既定の選択ツールは移動もリサイズもするので、**同じ ID で自前のツールを登録して置き換えます。** 組み込みの差し替えは、追加するのとまったく同じ呼び出しです。

```ts
class PickTool implements Tool {
  readonly id = 'select'      // 同じ ID なので既定のツールと入れ替わる
  // クリック・Shift クリック・範囲選択だけ
}

editor.tools.register('select', (e) => new PickTool(e))
```

**ハンドル。** ハンドルは要素なので、**CSS 1行で消えます。** `display: none` はタブ順からも外すので、ここではそれが正解です。リサイズするものが無いのだから、Tab で到達するものも無いべきです。

```css
.hc-app-pick .hc-handle {
  display: none;
}
```

**キャンバスに描かれたハンドルは、こうやって取り除けません。** 作者があらかじめ用意したフラグが必要になります。

ステージの帯だけは3つ目の方法をとっていて、`locked: true` です。ロックされたシェイプは範囲選択の対象から外れ、選択枠に `data-hc-locked` が付くので、**JavaScript なしでスタイルシートから反応できます。** [CSS 契約 →](/ja/api/css)
